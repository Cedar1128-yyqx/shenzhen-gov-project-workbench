# 深圳政企项目工作台

面向区域政府部门与企业项目对接的通用工作台，可按不同企业录入画像和项目资料。

## 在线访问

[打开当前公开版工作台](https://regional-ops-desk.cedar-0105.chatgpt.site/)

## 页面模块

- 政策与项目库：整理政策要点、适用条件、申报节点和来源。
- 企业画像与支持测算：录入企业情况，形成支持匹配和申报计划。
- 项目与部门协同：跟踪对接进展、问题责任部门和后续事项。
- 会议记录：按场次整理参会人员、职务与部门、进展、待解决问题及行动项。
- 拜访 Brief 与周报：汇总客户沟通准备、跟进状态和阶段性阻塞。

## 当前版本说明

这是一个可直接运行的前端演示页面，政策条目和企业案例含虚构样例；页面未连接实时政策抓取、OCR/录音转写、AI 模型、CRM 或政府申报系统。实际政策适用条件、申报材料与资助金额需要按对应部门发布的最新指南核实。

页面录入内容保存在当前浏览器的本地存储中，不会自动同步到其他设备或云端。请避免在公共设备录入敏感资料，并定期自行备份重要记录。

## GitHub Pages

仓库根目录的 `index.html` 已准备为静态网页。若需使用 GitHub Pages 域名打开：

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择分支 `main` 和目录 `/(root)`，点击保存。
4. GitHub 完成发布后，会在 Pages 设置页显示网站地址。
