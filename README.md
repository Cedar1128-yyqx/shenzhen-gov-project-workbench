# 深圳政企项目工作台

面向区域政府部门与企业项目对接的通用工作台，可按不同企业录入画像和项目资料。

## 在线访问

当前主线公开版：[打开工作台](https://cedar1128-yyqx.github.io/shenzhen-gov-project-workbench/)

## 页面模块

- 政策与项目库：整理政策要点、适用条件、申报节点和来源。
- 企业画像与支持测算：录入企业情况，形成支持匹配和申报计划。
- 项目与部门协同：跟踪对接进展、问题责任部门和后续事项。
- 会议记录：按场次整理参会人员、职务与部门、进展、待解决问题及行动项。
- 拜访 Brief 与周报：汇总客户沟通准备、跟进状态和阶段性阻塞。

## 企业公开资料联网检索

功能分支 `feat/company-web-enrichment` 增加企业名称检索与档案候选填入。首次使用需在企业档案的“联网检索服务”中输入个人 [Jina API Key](https://jina.ai/api-dashboard/key-manager)。工作台调用 Jina DeepSearch 搜索公开网页，展示字段来源和依据；用户核对并勾选后才写入企业档案。已有字段默认不覆盖。

API Key 仅保存在当前浏览器标签页的会话存储，不提交到 GitHub，也不放入企业档案。网页在浏览器中运行，Key 会由浏览器直接发送给 Jina；不要使用含有不必要权限的密钥。联网查询只发送企业名称，不发送企业档案中的财务或项目数据。服务额度和费用以 Jina 当前规则为准。

公开网页结果可能不准确或滞后。统一社会信用代码、法定代表人、注册地址、注册资本、经营范围、产品和股权关系都应按来源与企业材料核验。研发、销售、利润、税务、算力支出、资质、深圳申报主体和落地计划仍需人工填写，不从网页推断。

## 当前版本说明

这是一个静态前端工作台，政策条目和企业案例含虚构样例；页面未连接实时政策抓取、CRM 或政府申报系统。企业档案保存在当前浏览器本地，不会自动同步到其他设备或云端。

## GitHub Pages

仓库根目录的 `index.html` 是静态网页入口。合并到 `main` 后，若需发布更新，请确认 GitHub Pages 使用分支 `main` 和目录 `/(root)`。
